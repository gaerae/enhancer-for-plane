Quick open

In the address bar type issue, a space, then a work item key such as PROJ-123 — Enter opens it. The key’s prefix picks the target, so you can point ENG- at Linear and leave the rest on Plane; a target with an empty prefix is the default. Also on the toolbar popup.

Put {{key}} where the key belongs in the URL — {{key.proj}} and {{key.num}} are its two halves. A URL with no {{key}} gets the key appended to the end. The line under each row shows where a sample key would land.

Copy reference

On a work item page, the button beside its ID — or Alt/⌥+C — copies that item to your clipboard in one of the formats below. Use it to hand a work item to a chat message, a pull request, or a branch name.

Three values can be filled in: {{item.key}}, {{item.title}} and {{item.url}}. Everything else in a format is copied exactly as you typed it, so the preview under each row is what lands on the clipboard.

Body templates (title + body)

Pick one from the “Template” button next to “Attach” in an item's description toolbar — it fills the title and the body together. The title is optional.

The body is written in Markdown and rendered into the editor: ## headings, - / 1. lists, - [ ] checkboxes, **bold**, `code`.

Variables (filled on insert): {{date}} today, {{date+N}}/{{date-N}} N days from today (e.g. {{date+7}}), {{week}} this week's range (Mon–Sun), {{month}} as YYYY-MM. Shortcut: Alt/⌥+T opens templates while editing a description.

Share with your team saves your own templates as a file your teammates can subscribe to. Host it where they can reach it over https and give them the URL — they add it under Template sync below. Templates you received from a source are not included.

Template variables

Values you can drop into any template — your own and synced ones alike — as {{var.name}}. A synced template can say {{var.team}} and resolve to a different value for each person who inserts it.

The var. prefix keeps your names from ever clashing with the built-in {{date}}, {{week}} and {{month}}. A variable you have not defined stays visible as {{var.name}} rather than turning into an empty string.

Template sync

Pull shared templates from one or more URLs, checked on browser start, on a schedule, and when you open this page. Synced templates are read-only — edit them at the source. Host the file on the same domain as Plane to avoid a separate access prompt.

File format

A flat list; each item carries its own group string. The top-level name labels the whole collection and is used when you leave a source's name blank.

{
    "schema": 1,
    "name": "QA & Delivery standards",
    "version": "2026-07-15",
    "templates": [
      {
        "id": "bug",
        "group": "QA Templates",
        "name": "🐞 Bug",
        "title": "[Bug] ",
        "content": "## Steps\n1. \n"
      }
    ]
  }

Focus mode

A rule marked “Only while focus mode is on” stays out of the way until you ask for it. Two ship ready to use: hide a work item's properties panel, and hide the left navigation. A third caps the reading width and starts switched off.

Three ways in: Alt+Shift+F (macOS ⌥+⇧+F), the toggle beside a work item's key, and the switch in the toolbar popup. To rebind the shortcut, open chrome://extensions/shortcuts.

It applies to the tab you turned it on in, survives a reload there, and is gone once you close that tab. It never syncs to your other devices.

Style rules (width / length)

Force a property : value onto any CSS selector (with !important). If Plane's class names change, just edit the selector. Type the full value with units, e.g. 320px, 30rem, 55ch.

Backup

Export all settings (domains, style rules, templates, variables, and sync source URLs) to a JSON file, or import a previously exported file. Imported settings load into the form — review, then Save to apply.

The file lists your domains, source URLs and variable values in plain text — so if a variable holds your name, or those addresses are private, treat the file as internal. Synced templates are not included: they re-download from their source after you Save.

Settings sync across your devices via Chrome, which caps each item at ~8 KB. If you hit it, shorten/remove templates or keep a JSON backup.

Keyboard shortcuts

Everything the keyboard reaches, in one place. On macOS, Alt is ⌥ Option.

Does Windows · Linux macOS Where
Insert a body template Alt+T ⌥+T While editing a description, and in the “Create work item” dialog
Copy this work item's reference Alt+C ⌥+C On a work item — its own page, or the panel a list opens. Not while you are typing.
Turn focus mode on or off Alt+Shift+F ⌥+⇧+F Anywhere the extension runs, including while you are typing
Open a work item by key issue then the key issue then the key The address bar, on any tab

Focus mode is a browser command, so you can rebind it — or clear it — at chrome://extensions/shortcuts. The other two are handled inside the page and are fixed.

Alt+T is meant to be used mid-sentence, so it works while you type. Alt+C deliberately does not: on macOS ⌥+C is the character “ç”, and a shortcut that swallows it out of a title would take more than it gives. Focus mode escapes that trade-off by being a browser command, which Chrome intercepts before the page ever sees the key.
