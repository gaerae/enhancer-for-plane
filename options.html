Body templates (title + body)

Pick one from the “Template” button next to “Attach” in an item's description toolbar — it fills the title and the body together. The title is optional.

The body is written in Markdown and rendered into the editor: ## headings, - / 1. lists, - [ ] checkboxes, **bold**, `code`.

Variables (filled on insert): {{date}} today, {{date+N}}/{{date-N}} N days from today (e.g. {{date+7}}), {{week}} this week's range (Mon–Sun), {{month}} as YYYY-MM. Shortcut: Alt/⌥+T opens templates while editing a description.

Backup

Export all settings (domains, style rules, templates) to a JSON file, or import a previously exported file. Imported settings load into the form — review, then Save to apply.

Settings sync across your devices via Chrome, which caps each item at ~8 KB. If you hit it, shorten/remove templates or keep a JSON backup.
